#### [Manga Translator App](https://github.com/XanderAP25/Manga-Translator)
Manga Translator is a desktop application that automates the translation of Japanese manga pages into English. It leverages state-of-the-art OCR, object detection, and large language models to detect speech bubbles, extract Japanese text, translate it, and typeset the English translation back onto the manga pages.

The project was born from a desire to read manga that has not yet been translated into English, in particular fanworks. While I do intend to eventually pursue learning the language of the source material, this application serves as a bridge to enjoy these works in the meantime.
